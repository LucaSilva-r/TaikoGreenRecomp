# Notice

## What this repository contains

Hand-written host code only:

- `src/taiko_*.{c,cpp,h}` — title-specific host shims (arcade I/O board, ATRAC
  decoding, SPURS skinning, Lumen, networking).
- `src/gen/` — generated HLE stubs and the NID dispatch table.
- `ps3recomp/` — the vendored recompilation framework (see below).
- `tools/`, `scripts/`, `tests/`, `docs/`, `cmake/` — build and analysis
  tooling.

## What this repository does NOT contain

No game code, no game assets, no PS3 firmware, and no bytes derived from
either. Specifically absent, and refused by `.gitignore`:

- the game executable (`EBOOT.elf`) and any data from the
  dump;
- lifted PowerPC or SPU source generated from that executable (`src/recomp/`,
  `src/spu_gen/`);
- `ghidra_out/strings.json`, Ghidra's dump of the executable's string table;
- any PS3 firmware module (`*.prx`, `*.sprx`, `*.self`).

`meta/` and `ghidra_out/{functions,symbols}.json` **are** tracked. They hold
addresses, sizes, OPD and TOC values, Sony NIDs, and symbol names — measurements
of the executable's layout rather than any of its content. They are regenerable
from a dump with `ps3recomp/tools/`, and are kept in-tree so the analysis notes
throughout this repository resolve against something.

Building a runnable executable requires **your own legally obtained dump**.
The recompilation pipeline in `ps3recomp/tools/` produces the lifted sources
and metadata locally, on your machine, from that dump. Nothing about that
process is committed here.

## Vendored ps3recomp

`ps3recomp/` is a flattened copy of

    https://github.com/sp00nznet/ps3recomp

taken at upstream commit `82a1f96`, plus local changes made for this title.
It is used under the MIT License; see `ps3recomp/LICENSE` for the original
copyright (Ned Heller / sp00nznet) and `ps3recomp/CONTRIBUTORS.md` for
attribution. It was flattened rather than kept as a submodule because the
local divergence is substantial and is maintained here rather than upstream.

Upstream's `fw_spu/` directory is **not** carried. It held decrypted firmware
PRX images used as inputs to the firmware-LLE experiment, and no build in
either project references them. The tooling that consumes such a file —
`ps3recomp/tools/lift_prx.py` and `ps3recomp/docs/FIRMWARE_LLE.md` — is kept
intact, so the bring-your-own-firmware pipeline that upstream documents still
works if you supply your own decrypted module.

## Third-party build dependencies

`third_party/` holds locally installed prefixes (SDL3, SDL_shadercross,
SPIRV-Cross, DirectXShaderCompiler, a minimal FFmpeg). It is generated by
`scripts/setup_sdl_gpu_*.sh` and `scripts/build_ffmpeg_mingw.sh` and is not
tracked. Each dependency remains under its own upstream license.
